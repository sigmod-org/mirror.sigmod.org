PODS: Paper Formatting Instructions

Camera-ready submission instructions

Complete instructions for preparing the final version of accepted PODS papers are available here.

 

Draft submission instructions

Papers are to be submitted as a single PDF file, formatted for 8.5" x 11" paper. Submitted papers should be at most ten pages, using font size of 10pt. Templates on paper formatting are available in LaTeX (version 2e) and MS Word.

  • LaTeX
    • Sample File (PDF)
    • LaTeX2e Style File (CLS)
    • LaTeX2e Sample File (LaTeX)
    • ACM LaTeX2e Sample BIB File
    • Graphic #1 (EPS)
    • Graphic #2 (EPS)
    • Graphic #3 (PS)
  • MS Word

Additional details may be included in an appendix, which, however, will be read at the discretion of the program committee. Papers significantly deviating from the above formatting guidelines risk rejection without consideration of their merits.

Questions about any of the requirements listed on this page should be directed to the PODS 2009 Program Committee Chair: Prof. Jianwen Su (su [at] cs.ucsb.edu).
